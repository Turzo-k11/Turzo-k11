## 📂 Featured projects

### 📊 1. Supermart Sales Analysis
**Python · pandas · Matplotlib · Power BI**

Sales and profitability analysis of 9,994 grocery orders (2015–2018).

- **Growth:** sales rose 67% over four years, accelerating to +29% in 2018.
- **Seasonality:** Sep–Dec brings in 42% of annual sales, with November the peak month.
- **Drivers:** region, not product mix, separates performance. West and East account for 61% of sales while margins stay flat at ~25%.
- **Data quality:** detected and fixed mixed date formats that a standard parser misreads.

### 📱 2. Telco Customer Churn Prediction
**Python · scikit-learn · pytest · GitHub Actions**

Churn analysis and prediction for 7,043 telecom customers.

- **Business value:** contacting the 20% highest-risk customers reaches 50% of all churners, 2.5× better than random outreach.
- **Drivers:** month-to-month customers churn at 43% vs 3% on two-year contracts. Churn is 53% in the first six months.
- **Method:** cross-validated model selection, threshold chosen on training data only, ROC-AUC 0.85 on held-out test data.
- **Engineering:** automated tests run on every push via GitHub Actions.

[View project →](https://github.com/Turzo-k11/telco-churn-prediction)
